# Revofin

This folder holds two codebases and nothing else: `ekonomim` (front: web app, POS, landing, shared packages) and `revofin-api` (back: Spring Boot API). Work only in these two; no worktrees, clones or new folders. The parent `revofin/` folder is not a git repo, so run git commands inside each repo (`git -C ekonomim ...`, `git -C revofin-api ...`), commit explicit paths only (never `git add -A` or `commit -a`), and keep to the `feat/connected-sell-flow` branch in both. One session edits code at a time.
